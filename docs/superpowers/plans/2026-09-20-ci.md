# CI on GitHub Actions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the repo's checks on GitHub for every PR and every push to `main`, as four required-able checks: `pre-commit`, `commits`, `terraform`, `manifests`.

**Architecture:** One workflow, four parallel jobs, no path filters. `pre-commit` reuses `.pre-commit-config.yaml` as the single source of truth. The `manifests` job runs `scripts/check-manifests.sh`, which is also the local command. Nothing in CI touches secrets, the cluster or Proxmox.

**Tech Stack:** GitHub Actions, pre-commit, ansible-lint + collections from `ansible/requirements.yml`, Terraform 1.16 + tflint, kustomize, Helm 3, yq (mikefarah v4), kubeconform.

**Spec:** `docs/superpowers/specs/2026-09-20-ci-design.md`

## Global Constraints

- Branch is `ci-github-actions` (already exists, already holds the spec commits). Never commit to `main`, never merge, never push to `main`. The job ends at an open PR.
- Commits: Conventional Commits, subject ≤ 50 chars, imperative, lowercase, no trailing period, body wrapped at 72. Allowed types in the hook: `feat fix refactor perf style test docs build ops chore`; use `ops` for CI/tooling files.
- **No `Co-Authored-By` trailer on commits and no "generated with" line in the PR body.** CLAUDE.md overrides any default attribution.
- Workflow triggers: `pull_request` and `push` to `main`. **No path filters** (a skipped required check blocks merge forever).
- Workflow `permissions: contents: read`. Actions pinned by commit SHA. Tool versions pinned.
- Job names are exactly `pre-commit`, `commits`, `terraform`, `manifests` (they become the required-check names).
- `commits` runs on pull requests only.
- CI holds no secrets: no vault password, no tfvars, no kubeconfig. `ansible/secret.yaml` is ansible-vault ciphertext; never decrypt it, never `--syntax-check` with it.
- `proxmox/environments/prod` and `talos/` are never-applied scaffolding: not validated.
- `<path:...>` AVP placeholders are plain strings in this check. Never replace one with a real value.
- Read narrowly: `grep -n`, `sed -n`, `head`/`tail`. Do not `cat` whole files to inspect part of them.
- Check with `git check-ignore -v <path>` before assuming a new file is tracked.
- **ansible-lint has no ignore file and stays that way.** `ansible/.ansible-lint-ignore` was deleted and every finding fixed (merged in PR #27); the lint passes at profile `production`. Never recreate an ignore file or add a `skip_list`/`# noqa`: fix the finding.

### Task 3: `scripts/check-manifests.sh`

**Files:**
- Create: `scripts/check-manifests.sh` (mode 755)

**Interfaces:**
- Consumes: `kustomize`, `helm`, `yq` (mikefarah v4), `kubeconform` on `PATH`; network access to the Helm repos in the Application CRs and to `raw.githubusercontent.com` (CRD schemas).
- Produces: exit `0` when everything renders and validates, `1` when any check failed (after running all of them), `2` when a tool is missing. The CI `manifests` job runs it with no arguments from any directory.

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# Render everything ArgoCD would render from this repository and schema-check
# it: every kustomization, every Helm source in an Application CR, and the
# Application CRs and AppProject themselves. Runs in CI (the `manifests`
# job) and locally -- same command, same result.
#
# Needs on PATH: kustomize, helm, yq (mikefarah v4), kubeconform.
#
# <path:...> placeholders (argocd-vault-plugin) are plain strings here. They
# are resolved against Vault only at sync time, never in this check.
set -euo pipefail

cd "$(git rev-parse --show-toplevel)"

for tool in kustomize helm yq kubeconform; do
  command -v "$tool" >/dev/null || { echo "missing tool: $tool" >&2; exit 2; }
done

# Built-in Kubernetes schemas plus the datreeio catalogue for CRDs
# (Application, AppProject, ClusterIssuer, ServiceMonitor, ...).
CRD_SCHEMAS='https://raw.githubusercontent.com/datreeio/CRDs-catalog/main/{{.Group}}/{{.ResourceKind}}_{{.ResourceAPIVersion}}.json'
apps_dir=argocd/environments/dev/applications

work=$(mktemp -d)
trap 'rm -rf "$work"' EXIT
failed=0

schema_check() {
  kubeconform -strict -summary \
    -schema-location default -schema-location "$CRD_SCHEMAS" "$@"
}

fail() {
  echo "FAIL: $*" >&2
  failed=1
}

echo "== kustomize"
while IFS= read -r kfile; do
  dir=$(dirname "$kfile")
  echo "-- $dir"
  kustomize build "$dir" > "$work/out.yaml" || { fail "kustomize build $dir"; continue; }
  schema_check "$work/out.yaml" || fail "kubeconform $dir"
done < <(find argocd -name kustomization.yaml | sort)

echo "== helm"
for app in "$apps_dir"/*.yaml; do
  # A source with `chart:` is a Helm source; the plain git source is not.
  count=$(yq '[.spec.sources[]? | select(.chart)] | length' "$app")
  [ "$count" -gt 0 ] || continue

  name=$(yq '.metadata.name' "$app")
  ns=$(yq '.spec.destination.namespace' "$app")
  repo=$(yq '.spec.sources[] | select(.chart) | .repoURL' "$app")
  chart=$(yq '.spec.sources[] | select(.chart) | .chart' "$app")
  version=$(yq '.spec.sources[] | select(.chart) | .targetRevision' "$app")
  release=$(yq ".spec.sources[] | select(.chart) | .helm.releaseName // \"$name\"" "$app")

  # `$values/argocd/...` is ArgoCD's reference to the git source; locally
  # the same file is simply relative to the repository root.
  values=()
  while IFS= read -r vf; do
    [ -n "$vf" ] || continue
    values+=(-f "${vf#\$values/}")
  done < <(yq '.spec.sources[] | select(.chart) | .helm.valueFiles[]?' "$app")

  echo "-- $name ($chart $version)"
  helm template "$release" "$chart" --repo "$repo" --version "$version" \
    --namespace "$ns" --include-crds "${values[@]}" > "$work/out.yaml" \
    || { fail "helm template $name"; continue; }
  schema_check "$work/out.yaml" || fail "kubeconform $name"
done

echo "== argocd resources"
# Not the kustomization.yaml files: those are not Kubernetes objects.
mapfile -t plain < <(find argocd/base "$apps_dir" -name '*.yaml' ! -name kustomization.yaml | sort)
schema_check "${plain[@]}" || fail "kubeconform argocd resources"

if [ "$failed" -ne 0 ]; then
  echo "check-manifests: FAILED" >&2
  exit 1
fi
echo "check-manifests: ok"
```

- [ ] **Step 2: Make it executable and run it on the clean tree**

Expected: `check-manifests: ok`, `exit=0`, and a `Summary: N resources found ... Valid: N, Invalid: 0` line per section.

- [ ] **Step 3: Triage first-run failures**

Anything red here is a real finding about the repo or a gap in this script. Use only these fixes:
- `could not find schema for <Kind>` (kind missing from the datree catalogue): add `-skip <Kind>` to `schema_check` with a comment naming the kind and why (no published schema). Do not add `-ignore-missing-schemas`; it hides future gaps.
- A `<path:...>` placeholder in a non-string field (e.g. a port or replica count): report it to the user; do not change the manifest and do not weaken `-strict`. If the user agrees, substitute a dummy for that field only.
- A chart-specific `helm template` failure (e.g. a required value): report it; the values file is the user's.
- Everything else (an invalid manifest that would break ArgoCD today): report it. A genuine bug in a manifest is a separate PR.

Re-run Step 2 until `exit=0`.

### Task 4: The workflow

**Files:**
- Create: `.github/workflows/ci.yaml`

**Interfaces:**
- Consumes: `ansible/requirements.yml` (Task 1), `.tflint.hcl` (Task 2), `scripts/check-manifests.sh` (Task 3), `.pre-commit-config.yaml`.
- Produces: check contexts `pre-commit`, `commits`, `terraform`, `manifests`. The README (Task 5) names them.

- [ ] **Step 1: Write `.github/workflows/ci.yaml`**

```yaml
name: ci

# No path filters: with required checks, a workflow skipped by a path filter
# leaves its check pending forever and blocks merge.
on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read

concurrency:
  group: ci-${{ github.event.pull_request.number || github.ref }}
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}

env:
  PRE_COMMIT_VERSION: "4.6.2"
  ANSIBLE_LINT_VERSION: "26.8.0"
  TERRAFORM_VERSION: "1.16.2"
  TFLINT_VERSION: "v0.64.0"
  HELM_VERSION: "v3.22.0"
  KUSTOMIZE_VERSION: "5.8.1"
  KUBECONFORM_VERSION: "0.8.0"
  YQ_VERSION: "4.53.6"

jobs:
  # The repo's own hooks, unchanged: file hygiene, check-yaml, private-key
  # and gitleaks scans, ansible-lint, terraform fmt. ansible-lint and
  # terraform-fmt are `language: system` hooks, so the runner needs the
  # binaries and the collections in ansible/requirements.yml. No --syntax-check with
  # secret.yaml: it needs the vault password, which CI does not have.
  pre-commit:
    runs-on: ubuntu-24.04
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          fetch-depth: 0 # gitleaks
      - uses: actions/setup-python@5fda3b95a4ea91299a34e894583c3862153e4b97 # v7.0.0
        with:
          python-version: "3.12"
      - uses: hashicorp/setup-terraform@dfe3c3f87815947d99a8997f908cb6525fc44e9e # v4.0.1
        with:
          terraform_version: ${{ env.TERRAFORM_VERSION }}
          terraform_wrapper: false
      - name: Install pre-commit, ansible-lint and the collection
        run: |
          pip install "pre-commit==${PRE_COMMIT_VERSION}" "ansible-lint==${ANSIBLE_LINT_VERSION}"
          ansible-galaxy collection install -r ansible/requirements.yml
      - name: Run hooks
        run: pre-commit run --all-files --show-diff-on-failure

  # Same commit-msg hook as locally, run over every non-merge commit in the
  # PR. Not on push to main: GitHub's "Merge pull request #N" commits would
  # fail the convention.
  commits:
    if: github.event_name == 'pull_request'
    runs-on: ubuntu-24.04
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          fetch-depth: 0
      - uses: actions/setup-python@5fda3b95a4ea91299a34e894583c3862153e4b97 # v7.0.0
        with:
          python-version: "3.12"
      - name: Install pre-commit
        run: pip install "pre-commit==${PRE_COMMIT_VERSION}"
      - name: Check commit messages
        env:
          BASE_SHA: ${{ github.event.pull_request.base.sha }}
          HEAD_SHA: ${{ github.event.pull_request.head.sha }}
        run: |
          status=0
          msg=$(mktemp)
          for sha in $(git rev-list --no-merges "${BASE_SHA}..${HEAD_SHA}"); do
            git log -1 --format=%B "$sha" > "$msg"
            echo "-- $(git log -1 --format='%h %s' "$sha")"
            pre-commit run conventional-pre-commit \
              --hook-stage commit-msg --commit-msg-filename "$msg" || status=1
          done
          exit "$status"

  terraform:
    runs-on: ubuntu-24.04
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
      - uses: hashicorp/setup-terraform@dfe3c3f87815947d99a8997f908cb6525fc44e9e # v4.0.1
        with:
          terraform_version: ${{ env.TERRAFORM_VERSION }}
          terraform_wrapper: false
      - uses: terraform-linters/setup-tflint@1cf010d3c7aef302051ccdb68c14c5dc2efa34ef # v6.3.1
        with:
          tflint_version: ${{ env.TFLINT_VERSION }}
      # backend.tf is gitignored, so -backend=false is the only init that
      # can work here; validate needs no variables and no credentials.
      - name: terraform init and validate
        run: |
          terraform -chdir=proxmox/environments/dev init -backend=false -input=false
          terraform -chdir=proxmox/environments/dev validate
      - name: tflint
        run: tflint --chdir=proxmox/environments/dev --config="${GITHUB_WORKSPACE}/.tflint.hcl"

  manifests:
    runs-on: ubuntu-24.04
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
      - uses: azure/setup-helm@9bc31f4ebc9c6b171d7bfbaa5d006ae7abdb4310 # v5.0.1
        with:
          version: ${{ env.HELM_VERSION }}
      - name: Install kustomize, kubeconform and yq
        run: |
          bin="$HOME/.local/bin"
          mkdir -p "$bin"
          gh="https://github.com"
          curl -fsSL "${gh}/kubernetes-sigs/kustomize/releases/download/kustomize%2Fv${KUSTOMIZE_VERSION}/kustomize_v${KUSTOMIZE_VERSION}_linux_amd64.tar.gz" \
            | tar -xz -C "$bin" kustomize
          curl -fsSL "${gh}/yannh/kubeconform/releases/download/v${KUBECONFORM_VERSION}/kubeconform-linux-amd64.tar.gz" \
            | tar -xz -C "$bin" kubeconform
          curl -fsSL -o "$bin/yq" "${gh}/mikefarah/yq/releases/download/v${YQ_VERSION}/yq_linux_amd64"
          chmod +x "$bin/yq"
          echo "$bin" >> "$GITHUB_PATH"
      - name: Render and schema-check manifests
        run: scripts/check-manifests.sh
```
