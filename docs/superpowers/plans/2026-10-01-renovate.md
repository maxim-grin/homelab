# Renovate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The hosted Renovate app opens reviewed pull requests for the pins this repository carries, without merging anything itself and without breaking CI on its own commit titles.

**Architecture:** One `renovate.json5` at the repository root: `config:recommended`, a weekly schedule, the built-in `argocd` manager pointed at the Application CRs, one regex custom manager that reads `# renovate:` comments above the CI and Ansible-role pins, and package rules that gate hash-bearing pins behind a Dependency Dashboard tick and silence noise. The `commits` CI job skips `renovate[bot]`'s pull requests. Docs and an ADR record the decision.

**Tech Stack:** Renovate (hosted Mend Community app; validated locally with the `renovate/renovate` Docker image), GitHub Actions, JSON5, Ansible role defaults.

**Spec:** `docs/superpowers/specs/2026-10-01-renovate-design.md`

## Global Constraints

- Branch `renovate-config`, already open as draft PR #72 and carrying the spec. Never commit to `main`, never merge, never push to `main`; an agent's job ends at the PR (`gh pr ready 72` once the work is verified).
- Commits: Conventional Commits, subject ≤ 50 characters, imperative, lowercase, no trailing period, body wrapped at 72. Types: `feat fix refactor docs chore ops`. There is no `ci` type.
- **No `Co-Authored-By` trailer and no "generated with" line** in commits or the PR body. CLAUDE.md overrides any default attribution.
- Config file is `renovate.json5` (not `.json`) so it can carry comments.
- No automerge anywhere. Schedule `before 7am on monday`, timezone `UTC`, `prConcurrentLimit` 3, label `deps`.
- `ignorePaths` is exactly `terraform/environments/prod/**` and `talos/**`, with a comment pointing at ADR 0021 and sub-project 2.
- Hash-gated `depName`s (exact): `gitleaks/gitleaks`, `kubernetes-sigs/kustomize`, `yannh/kubeconform`, `mikefarah/yq`, `traefik/traefik`, `TwiN/gatus`, `291-Group/LAN-Orangutan`, `glanceapp/glance`.
- Never read or decrypt `ansible/secret.yaml`. Never run a playbook or `terraform plan`/`apply`.
- Tools: `$SCRATCH` is the scratchpad; Docker runs `renovate/renovate:latest` (the host's Node 22 is too old for the latest `renovate` from npm). Read narrowly: pipe Renovate's debug log through a filter, never print it whole.
- ADR number is 0021 (0020 is on PR #65, not yet merged). If #65 has merged when Task 3 runs, rebase; the ADR index row is the only conflict.

## Review Focus

- **A bare bump of a hash-bearing pin**: must not open a PR on its own. Task 1 puts all eight names under `dependencyDashboardApproval`. The gate only shows in the Dashboard once the config is on `main`, so Task 4 (owner) checks it there.
- **Renovate PR titles**: `chore(deps): update … to …` run past 50 characters. Task 2 skips the `commits` job for `renovate[bot]`; Task 4 checks it on the first real PR.
- **Prod and `talos/`**: no dependency from either may appear. Task 1's dry run asserts none does.
- **Noise**: the `ubuntu` runner image and `python` setup version must not produce PRs. Task 1's dry run asserts both are disabled.
- **Pins on open PRs** (Glance on #65): not annotated yet; the later PR adds its own `# renovate:` comment (spec, "What it tracks").

- [x] **Step 2: Annotate the pins**

Each pin gets one `# renovate:` comment on the line above it, indented like the pin. `extractVersion` strips the tag's `v` (or kustomize's `kustomize/v`) so the file keeps its current style.

```bash
cd /home/ubuntu/homelab
python3 - <<'EOF'
import re

def annotate(path, pairs):
    s = open(path).read()
    for key, comment in pairs:
        m = re.search(r'^(\s*)' + key + r':', s, re.M)
        assert m, f"{key} not found in {path}"
        s = s[:m.start()] + m.group(1) + '# renovate: ' + comment + '\n' + s[m.start():]
    open(path, 'w').write(s)

gh = 'datasource=github-releases'
v = 'extractVersion=^v(?<version>.+)$'
annotate('.github/workflows/ci.yaml', [
    ('PRE_COMMIT_VERSION', 'datasource=pypi depName=pre-commit'),
    ('ANSIBLE_LINT_VERSION', 'datasource=pypi depName=ansible-lint'),
    ('TERRAFORM_VERSION', f'{gh} depName=hashicorp/terraform {v}'),
    ('TFLINT_VERSION', f'{gh} depName=terraform-linters/tflint'),
    ('HELM_VERSION', f'{gh} depName=helm/helm'),
    ('KUSTOMIZE_VERSION', f'{gh} depName=kubernetes-sigs/kustomize extractVersion=^kustomize/v(?<version>.+)$'),
```

- [x] **Step 3: Write `renovate.json5`**

```json5
{
  $schema: "https://docs.renovatebot.com/renovate-schema.json",
  extends: ["config:recommended"],
  timezone: "UTC",
  schedule: ["before 7am on monday"],
  prConcurrentLimit: 3,
  labels: ["deps"],
  semanticCommits: "enabled",
  // Never-applied scaffolding (CLAUDE.md). Remove both entries when
  // roadmap sub-project 2 (Talos prod) is done; see ADR 0021.
  ignorePaths: ["terraform/environments/prod/**", "talos/**"],
  argocd: {
    managerFilePatterns: ["/^argocd/environments/.+\\.ya?ml$/"],
  },
  customManagers: [
    {
      customType: "regex",
      managerFilePatterns: [
        "/^\\.github/workflows/ci\\.yaml$/",
        "/^ansible/roles/[^/]+/defaults/main\\.ya?ml$/",
      ],
      matchStrings: [
        "# renovate: datasource=(?<datasource>\\S+) (?:registryUrl=(?<registryUrl>\\S+) )?depName=(?<depName>\\S+)(?: extractVersion=(?<extractVersion>\\S+))?\\n\\s*\\w+: \"?(?<currentValue>[^\"\\s]+)\"?",
      ],
    },
  ],
  packageRules: [
    {
      // A version with a companion SHA-256 or digest (ADR 0017) cannot
      // pass as a bare bump: no PR until the owner ticks it in the
      // Dependency Dashboard and pushes the new hash.
      matchDepNames: [
        "gitleaks/gitleaks",
        "kubernetes-sigs/kustomize",
        "yannh/kubeconform",
        "mikefarah/yq",
        "traefik/traefik",
        "TwiN/gatus",
        "291-Group/LAN-Orangutan",
        "glanceapp/glance",
      ],
      dependencyDashboardApproval: true,
    },
    {
      // Noise, not pins we chose: the `runs-on` image and setup-python.
      matchDepNames: ["python", "ubuntu"],
      enabled: false,
    },
  ],
}
```

- [x] **Step 2: ADR 0021**

Create `docs/decisions/0021-renovate-hosted-app.md` with, in ADR 0019's format (`# 0021. …`, `**Status:** Accepted (2026-10-01)`, Context, Decision, Consequences, Related):

- **Context:** pins (CI tool versions, role versions, Helm charts, providers, Actions) go stale silently; a merge is a deploy, so updates must stay reviewed; several pins carry a companion hash (ADR [0017](0017-verify-lan-service-binaries-sha256.md)).
- **Decision:** the hosted Mend Renovate Community app on this repository only, config in `renovate.json5`; no automerge; hash-bearing pins wait for a Dependency Dashboard tick; weekly schedule (Mondays before 07:00 UTC), three open PRs at most; Renovate PRs are squash-merged by the owner with a short Conventional subject and the `commits` job skips `renovate[bot]`; everything else keeps merge commits. Rejected: Dependabot (cannot read Ansible defaults, the CI `env` block or Helm `targetRevision`), self-hosted Renovate (could recompute hashes but needs a stored GitHub token and a job, for a bot that can write to a repo where a merge is a deploy).
- **Excluded until sub-project 2:** `terraform/environments/prod` and `talos/` (never-applied scaffolding; Renovate's defaults would silently "fix" prod's provider pin). **Remove both `ignorePaths` entries in `renovate.json5` when roadmap sub-project 2 is done.**
- **Consequences:** a bump of a hash-bearing pin needs its new hash pushed to the branch by hand (commands in `docs/operations.md`); the hosted app holds write access to this repository through its install; pins on pull requests open at the time of writing (Glance, #65) get their `# renovate:` comment from that PR; the `argocd_version` pin is the Argo CD Helm chart, whose companion `quay.io/argoproj/argocd` image tag in the same defaults file is not tracked and must be bumped by hand to match when the chart's app version changes.
- **Related:** the spec `docs/superpowers/specs/2026-10-01-renovate-design.md`; ADR 0017; `renovate.json5`.

Add the index row after 0019's.
